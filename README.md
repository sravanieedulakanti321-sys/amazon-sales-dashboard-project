# Amazon Sales Data Visualization

## Internship Project

This project analyzes Amazon sales data using *Tableau and Power BI* to create meaningful dashboards and business insights.

### Tools Used
- Tableau
- Power BI
- CSV

### Visualizations
- Sales Trend
- Sales by Category
- Top States by Sales
- Order Status
- Fulfilment Analysis
- Key Performance Indicators (KPIs)

### Objective
To transform raw Amazon sales data into clear visualizations that help understand sales performance, product trends, and business patterns.
